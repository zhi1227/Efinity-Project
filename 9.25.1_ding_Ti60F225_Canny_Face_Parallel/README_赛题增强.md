## 板上操作

只用小核心板上的 **K1、K2**，不要用 K3。K3 是硬件配置复位。

| 操作 | 作用 |
|---|---|
| 上电/复位 | 默认模式 3；实时显示 LIVE；阈值 40/80 |
| K1 按下并松开 | 模式加一：3→4→…→13→0→1→2→3 |
| K2 按下并松开 | 冻结当前显示帧，再按恢复最新完整帧 |
| 长按 K1/K2 | 只触发一次，不连跳 |
| 上电时按住按键 | 必须先稳定松开再按，不自动触发 |

两个按键均同步并对按下/松开消抖约 20ms。冻结实际在 DDR 读帧边界提交，LIVE/HOLD 提示也在显示帧边界提交，因此可能稍后一个显示帧才更新。HOLD 字样为黄色。冻结后可继续切换模式，对**同一张 DDR 原图**观察不同处理结果。

K1 = GPIOL_P_02 / N2；K2 = GPIOL_N_02 / M2；均 1.8V、低有效、板上外部上拉。K2 原来被闲置并行 LCD 时钟输出占用，本轮改成输入。**不得同时连接并行 LCD。** 摄像头/DDR/HDMI 的引脚、PLL、时序约束没有改动。

### 关于 Sobel 和 Canny 的取舍

借鉴同级 Sobel 工程的是“`min(abs(Gx)+abs(Gy),255)` 强弱显示”和赛博色表，并未复制第二套相机、DDR、HDMI。算子使用本主工程经独立参考验证的标准 Sobel、中心坐标与有效区，不能简单把旧工程输出时序拼接过来。

- 基础模式 5：灰度→中值→Sobel→二值。
- 清晰细节模式 8/9/10：灰度→Sobel，保留或映射幅值，不经 NMS。
- 去噪细节模式 13：灰度→中值→Sobel 幅值。
- Canny 模式 1～4：灰度→3×3 高斯→Sobel→NMS→双阈值→局部连接。
- 人脸肤色分支没有换模型或盲调参数；原先的误框/漏框问题不会因显示增强自动解决。

高斯核 `[1 2 1;2 4 2;1 2 1]/16`，加 8 后右移 4 四舍五入，12bit 加权和；与中值滤波同样 1 拍寄存延迟。Canny 的 40/80 是沿用起点，**尚无真实数据证明已优化**。

真正完整滞后需保留含强边的像素级弱边连通分量。720p 仅 2bit 分类帧就约 225KiB、180 个理想 RAM10，还未算队列；本版剩 70 个 RAM 块，不能直接塞进去。后续要单独设计 DDR 算法帧区、访问调度、带宽/延迟与一致性，不把局部连接冒充完整 Canny。

### 模式 12 怎么演示

1. 摄像头前放纯色背景/纸张，中央青框内只放一个完整的黑色圆或轴对齐矩形。
2. 图形要与青框四边留出空隙，避免手、文字、桌面纹理同时进入；保持约两帧以上不动。
3. `RECT`＋绿框：矩形候选；`CIRC`＋粉框：圆候选；`NONE`：未达到条件。
4. 移走目标应清空结果。移动/旋转/遮挡、椭圆、复杂背景可拒绝或误判，不属于精准分类保证。

算法不是画固定模板：从二值 Sobel 收集实际边缘包围盒；下一帧按该盒统计四边支持和圆半径带支持，检查尺寸、支持比例、稀疏程度、四象限和帧间框变化。框按实测边缘输出；青框只是明确可见的检测范围。

## 冻结实现与修正

`src/axi/frame_buffer_select.v` 在 AXI 时钟域管理四个 DDR 槽位：K2 请求经过两级同步；只在读帧初始化边界保持或更新读索引；写指针一直跳过显示槽，摄像头继续采集其他槽。恢复选最新完整提交帧，不停止 HDMI 时钟、DE 或采集数据使能。

启动时不能冻结尚未装入有效图像的默认槽。读写同时提交时同步维护 latest，修复旧代码该分支遗漏更新 latest 导致下一次读帧可能回退旧帧的问题。测试包含随机事件、读写同时发生、长时间保持、恢复与复位。

此验证针对帧槽选择及既有控制接入，不是外部 DDR 电气波形、全 AXI 背压协议或整板无丢帧证明。既有 DDR IP/FIFO/突发读写状态机未重写。
