| 复位行为 | 复位/上电/串口 `r` 恢复 40/80；**不写入 Flash** | README |
| 共享通路 | Canny 用高/低双阈值；部分 Sobel 显示也使用低阈值；冻结后的**原图可用新阈值重新处理** | README |
| 新增回归 | `tools/test_threshold.ps1`（按键、数值边界、Canny 输入、跨时钟、帧边界、LCD/HDMI 像素输出） | README + `reports/tb_threshold_*.log` |
| 按键与 UART 的仲裁 | **UART 的模式命令优先级高于 K1 按键事件**；阈值命令或未知字节**不会吞掉按键事件**（`uart_params.v` 第 68 行注释与实现） | `uart_params.v` |
