## 0. 分析方法与文本噪声说明（**写作指南必须规避的坑**）

原始提取文本存在明显的**公式/数字丢失**现象，这是"字体缺失 + OMML 公式未被提取"造成的，不是作者写错：

| 原文位置 | 提取后残缺形态 | 推断原意 |
|---|---|---|
| §1.1 高精度测量 | "采用**位**Σ-Δ型芯片" / "**-毫伏级**电压分辨率" | "采用 16 位 Σ-Δ 型芯片" / "0.1 毫伏级" |
| §1.2 主要技术特点 | "**⁻²**毫伏级"、"**±.** 定位精度"、"**端（核）与端（逻辑）**" | "10⁻² 毫伏级"、"±0.01 mm"、"PS 端（ARM 核）与 PL 端（FPGA 逻辑）" |
| §2.1 | "模块：设有首页…" | 前缺主语"屏幕/HMI 模块：" |
| §3.3.2 | "逻辑功能"、"eeprom 使用了 90 %以上" | 正常，但**"90%"缺动词对象**（指存储容量占用率） |

**可复用结论**：技术文档中凡涉及型号、位宽、单位、精度，**必须用纯文本写出完整数字与单位**（如 `16 位`、`0.1 mV`、`±0.01 mm`），不要仅以公式域或特殊字体承载——评委与检索系统都会读不到。

### 1.2 编者提示语（**原文摘录**，模板自带的要求）

以下四句是模板**直接写在标题里**的编者要求，是最硬的模板证据：

| 出处 | 原文摘录 | 隐含的填写要求 |
|---|---|---|
| §2.2.3 标题 | **"电路各模块介绍（从总体到局部，逐级给出各模块的具体设计图，并标记"**（句子在模板中被截断） | ① 必须**自顶向下**逐级分解；② 每个模块**都要配设计图**；③ 图上要**标注接口/信号名** |
| §3.1 标题 | **"整体介绍（整个系统实物的正面、斜45°全局性照片）"** | 至少 2 张实物照：正面 + 斜 45°；且必须是**全局**照 |
| §3.2 标题 | **"工程成果（分硬件实物、软件界面等设计结果）"** | 成果必须**分类**呈现：硬件实物、软件界面各成小节 |
| §3.3.1 标题 | **"关键性能指标（实测/工程值）"** | 指标必须区分**实测值 / 工程值**，不能只写设计目标 |

> **注意**：报告中 §2.2.1、§2.2.2、§3.1、§3.2、§3.3.1 等标题**原样保留了模板的括号提示语**未删除。这说明——**成熟做法是把提示语当成分节的小标题一并保留**，或至少保证该节严格满足提示语要求。写作指南应明确：**提示语 = 评分点，写了就要有对应内容**。

### 1.3 编号体系的两套并行

- **章标题样式**（自定义）：用于 `摘要`、`参考文献` —— 不进正文编号序列。
- **Heading 1/2/3**：进自动编号（1、1.1、1.1.1…）。
- **失效现场**：§4 下出现 `4.24`、`4.35`、`4.44.1 可扩展之处` 三段 `List Paragraph` 残留数字，是自动编号与人手输入编号**打架**的产物（应为 4.1、4.2…）。
- **失效现场 2**：§2.3.1、§2.3.2、§3.2.1~3.2.3、§3.3.1~3.3.2 被写成**纯文本**（Body Text）而非 Heading 3。

**指南规则**：**全文只用一套编号机制**（推荐手写纯文本编号，因为 Word 自动编号在转换/复制时必然错乱），且**所有同级小节必须使用同级标题样式**，否则无法生成目录。

### 2.2 逐章实际写法

**摘要（3.9%）**
- 结构固定为四段：① 一句话总述（平台 + 设计理念 + 目标）；② "系统硬件架构由五大核心模块组成："+ (1)~(5) 分条，**每条 = 模块名 + 器件/方案 + 量化指标 + 作用**；③ 一句 FPGA 全终端部署与场景定位；④ 一句升级/扩展空间。
- **特点**：不出现任何图，纯文字；每模块 1–3 句，总长 < 1 页。

**§1.1 功能与特性**：4 条并列 `小标题：内容`，顺序 = 测试设计 → 高精度测量 → 全自动定位与测试 → 国产化适配与平台移植。

**§1.2 应用领域**：**单段超长文**（约 400 字），按 **材料测试 → 集成电路产业 → 高校教学 → 国产化替代 → 未来展望** 五级递进，每级一句"场景 + 价值"。是全文最长的一段。

**§1.3 主要技术特点**：5 条并列 `小标题：内容`（硬件架构 / 算法优化 / 协同控制 / 国产化技术 / 应用效能），每条带量化数字；末条以"适用场景扩展 3 倍以上"收尾。

**§1.4 主要性能指标**：**只有一张 15×2 表**，零散文字，标题下直接插表。

**§1.5 主要创新点**：**17 条纯列表**（无编号，靠缩进/项目符号），每条 1 句、10–25 字，前半段为"能力命名 + 说明"，末尾 3 条转为**成本/体积/功耗/性价比**类商务型卖点（"整机成本仅为 RTS-8 的百分之一"），最后配 1 张对比图（图1.5.1）。

**§1.6 设计流程**：**1 段（拆成 2 个 Body Text）流水账式叙述** + 1 张流程图（图1 设计流程图）。叙述顺序 = 需求分析 → 机械/电路方案 → PL 端实现 → PS 端开发 → 算法库 → 多点测量与可视化 → 联调标定 → 历史记录/报表 → 实验验证。

**§2.1 整体介绍**：先 1 张系统整体框图（图2.1），再 1 段**高密度技术总述**（约 500 字，含 SPI/AD7606/IIR/µV/AXI/DDR/中断/软串口帧/修正因子/迁移率模型等全部关键名词），随后用 4 小段分述"模块（HMI）""开发板模块""三维步进电机平台""流程"，末段用 `>>` 串起**开机操作流程**。

**§2.2 硬件系统介绍**：三级结构 + 每级**一张框图 + 一段文字**，严格对应模板要求的"从总体到局部"：
- 2.2.1 硬件整体介绍 → 图2.2.1 硬件框架图 → 列出"DR1 主控板 + 自研 XYZ 驱动板 + 屏幕 + 恒流源 + 四探针夹具/晶圆"并说明 PL/PS 分工。

**§3.3 特性成果**：`3.3.1` 用 6 条 bullet 给关键指标（分辨率、SNR、恒流源、测点模式、输出量、系统形态），再用 **"九点样例实测"演示数据** 给出电压热图/电阻率热图/掺杂浓度反演区间/均匀性 ±3.1%/时延 ≤1 s per point/九点总时长 10–20 s；`3.3.2` 用 **"常规 UI vs 本产品 UI"** 对比，落到 3 点（逻辑功能与资源使用 3000 行代码 / 界面美化 / 便携性），并配 3 张图（本产品 UI、传统 RTS-9、本项目整机）。

**§4 总结**：`可扩展之处` 分 2 大块：① 面向产业与科研的**五层扩展**（算法层/计量层/系统层/材料生态/硬件层，用 ①②③④⑤）；② 5 条未来方向（高低温/薄膜纳米/AI 分析/便携模块化/多场景）。`心得体会` 用 **"其一/其二/其三"** 三点方法论（计量先行、物理反演优先、系统化与可追溯）+ 1 段**踩坑复盘**（DDR test_data 位导致 ch7 未入帧、2400 bps 三点多数表决、CRLF 回退）+ 1 段升华展望。

### 2.3 该报告的"写法配方"（可直接复用）

1. **每条技术点 = 名词化标题 + 冒号 + 方案 + 量化结果**（如"协同控制：…实现 ±0.01 mm 定位精度"）。
2. **每节 = 图在前、讲解在后**（先放框图，再用文字走一遍数据流），28 张图里 25 张是自绘框图/界面截图。
3. **函数级 API 清单**承担"软件详细设计"的举证责任，可读性远高于散文。
4. **收尾必给对比**：创新点配 RTS-8 对比图、UI 配 RTS-9 对比图——**用"vs 传统商用仪器"完成价值论证**。

### 3.2 正文散落的量化指标（按类别）

**分辨率 / 精度类**
- 电压采样分辨率 **0.1 mV**（16 位 ADC + IIR 平滑）；表内写作 0.15258789 mV；§1.3 写作"10⁻² 毫伏级"→ **同一指标三处三个写法**（⚠️ 指南须要求"全篇同一指标只用一个口径"）。
- 恒流源 **0.01–100 mA** 可编程（§2.1、§3.3.1）；表内写作 **10 µA–1 A 六档**（⚠️ 两处口径不一致：0.01–100 mA vs 10 µA–1 A）。
- 定位精度 **±0.01 mm**（§1.3）；接触阈值 **约 −1 mV**。
- 四探针间距 **1 ± 0.01 mm**；探距 **0.5 cm 步距**（§3.2.1 称默认步距 0.5 cm，与探针间距 1 mm 属不同量，需注意读者混淆）。

**速率 / 时延类**
- 采样时钟 **100 MHz** 域；爆发采样窗口 **T = 200 ms**，**fs ≈ 5 kHz**（两者相乘 ≈ 1000 点/点）。
- 单点测量时间 **≤ 1 s/点**；九点总时长 **10–20 s**（0.5 cm 步距）；估计值在 **100–150 ms** 趋于稳定。
- SD 串口 **2400 bps**，HMI 固定帧 **22 B**（AA..FF）；恒流源应答超时 **150–300 ms**；DDR 帧 **1 MB/帧**、**三缓冲环**。

**信号质量类**
- 等效 **SNR > 110 dB**（"按 20 kHz 带宽估算"）；§2.2.3 与 §3.3.1 两次给出，均标注估算带宽。

**被测对象 / 输出类**
- 掺杂浓度反演范围 **~1×10¹² – 1×10¹⁸ cm⁻³**（§2.3）；§4 心得体会写作 **10¹²–10¹⁹ cm⁻³**（⚠️ 上界不一致）。
- 九点实测样例（I = 1 mA，W = 645 µm）：电压 V 中心 **≈ 6.00 mV**，最大 **6.25 mV**，最小 **5.88 mV**；薄层近似 ρ ≈ 4.532·W·(V/I) 得九点 ρ 平均 **≈ 1.76 Ω·cm**，极差 **1.72–1.83 Ω·cm**，均匀性 **≈ ±3.1%**（极差/均值）；N ≈ **(3.4–3.7)×10¹⁵ cm⁻³**，均值 **≈ 3.6×10¹⁵ cm⁻³**（C–T 模型，300 K）。

**算法 / 工程参数类**
- IIR 一阶 **y += (x−y) >> ALPHA_SHIFT，默认 1/16（s = 4）**；PL `SCALE_MV = 10 000 000 µV`（±10 V 满量程）。
- 稳健估计：**分位预选 + MAD 去异常 + 10% 裁剪均值**。
- 修正因子：**F(W/S)** 级数近似至 **n = 200**，**α = 1.386** 处薄/厚域模型切换；**F(D/S)** 分段插值；**F_sp ≈ 1.001**。
- 资源与成本：**代码约 3000 行**全自主编写；**EEPROM 使用 90% 以上**；**全系统仅 1 颗 DR1 芯片**；**整机成本为 RTS-8 的 1%（百倍成本优势）**；**适用场景扩展 3 倍以上**。
- 供电：逻辑端 **3.3 V**。

### 3.3 测试方法（报告如何交代"怎么测的"）

| 方法 | 原文依据 | 套路总结 |
|---|---|---|
| **标准片比对法** | "用硅标样片 0.01–50 Ω·cm 测试 ≤ ±5%" | 误差指标必须绑定标准器与量程段 |
| **标样/对比仪器交叉比对** | §4 "与标准片/对比仪器交叉比对…形成量值溯源链" | 把溯源链写进展望 |

| **薄层近似公式反算** | ρ ≈ 4.532·W·(V/I)，I = 1 mA，W = 0.0645 cm | **写出公式与代入值**，让读者可复算 |
| **窗口内时序判据** | 200 ms / 5 kHz 窗口，100–150 ms 稳定 | 用"稳定时间"论证重复性 |
| **上电自测** | 通道零漂、有效位宽、阈值触发检查 | 自检项即可靠性证据 |

### 4.1 六小节的"套路"提炼

1. **顺序是"功能 → 场景 → 技术 → 指标 → 创新 → 流程"**：先讲"能干什么"（外行也能读），再讲"卖给谁"，然后"凭什么做到"，用表把指标钉死，用列表把创新点讲成卖点，最后用流程图闭合"怎么做的"。
2. **每条起手必是"名词化小标题 + 冒号"**（"测试设计：""硬件架构：""适配硅片类型更广："），使小节可被扫读。
3. **信息密度呈"哑铃形"**：1.2 应用领域极稀（散文）、1.4 极密（表）、其余中等。**不要在小节里平均用力**。
4. **概述不重复正文细节**：§1 只出现结论性数字（0.1 mV、±0.01 mm、3 倍），实现细节（SPI 时序、IIR 移位、修正因子阶数）全部留给 §2。
5. **创新点用"清单倾泻"策略**：17 条远超常规 3–5 条，用数量营造"功能密度"；末条以成本优势作情绪高点。
6. **每小节 1 图上限**：概述章只放 2 图（流程图 + 优势对比图），避免抢占正文图表配额。
