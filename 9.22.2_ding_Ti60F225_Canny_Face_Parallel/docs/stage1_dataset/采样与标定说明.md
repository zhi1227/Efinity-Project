## 应提供什么

至少五组：正脸不同距离；侧转/眼镜/阴影；手靠近脸；暖色或肤色背景；无人负样本。每组包含静止与连续运动，多种光照，调参tune与验收validation分开。

优先直接保存OV5640原始RGB565。当前工程没有整帧串口导出模块，本阶段没有为此改变DDR或板级。如使用HDMI采集卡捕获原图，写明capture_source、分辨率、色彩空间/压缩，不与直接原始数据混为一谈。不要用拍显示器的照片标定肤色阈值。

同时记录曝光/白平衡是否稳定、距离、光照、原始源帧序号、时间戳；重复显示同一相机帧不能假装独立样本。

## 标注格式

复制 [template.json](D:/yilingsi_fpga/Efinity_Project/2026.9.22/9.22.2_ding_Ti60F225_Canny_Face_Parallel/docs/stage1_dataset/template.json)，填入真实文件与标注。以下仅为格式示例，不代表已存在样本：

```json
{
  "schema_version": 1,
  "capture_source": "OV5640 raw RGB565, record exposure/AWB settings here",
  "width": 1280,
  "height": 720,
  "frames": [
    {
      "id": "front_0001",
      "file": "frames/front_0001.rgb565",
      "format": "rgb565_le",
      "scene": "front",
      "split": "tune",
      "labelled": true,
      "boxes": [[400, 160, 639, 479]],
      "sequence": "front_static_01",
      "source_frame_id": 1,
      "timestamp_ms": 0
    },
    {
      "id": "empty_0001",
      "file": "frames/empty_0001.png",
      "format": "rgb888_image",
      "scene": "empty",
      "split": "validation",
      "labelled": true,
      "boxes": []
    }
  ]
}
```

- 支持rgb565_le（低字节在前）、rgb565_be、rgb888_image（Pillow可读取的图像，优先无损PNG）。
- RGB565每像素2字节，文件大小必须等于width×height×2。输入图像不会自动缩放。
- 坐标为包含端点的[x0,y0,x1,y1]，与RTL一致；不要混用[x,y,w,h]。
- labelled=true且boxes=[]才表示人工确认无人；未标注的图片用labelled=false，不能当负样本。
- id仅用英文、数字、下划线、连字符，且唯一。file相对manifest所在目录。
- 离线脚本不模拟检测框的后台处理丢帧/帧边界延迟；实际动态帧龄、抖动需另外采集，不能由静态指标推出。

在主工程目录运行，替换manifest路径与输出目录。输出目录必须不存在，不会覆盖既有运行：

```powershell
& 'C:\Users\Lenovo\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' '.\tools\stage1_reference.py' --dataset '.\docs\stage1_dataset\my_samples.json' --output '.\reports\stage1_20260924\real_baseline_01' --profile baseline
```

可用profile：baseline、ratio12、fill40、cell16、cell32、ymin32。每个非baseline档只改变一个离线变量；**不会修改RTL、生成bit或自动选定赢家**。一次一个档，与同一批数据的baseline比较，最后用独立validation场景检验。

每帧输出：

- gray.png：整数灰度；
- raw_skin.png：原始肤色；
- majority.png：多数处理；
- clean_skin.png：腐蚀后，含两像素零边界；
- grid.png：8×8网格占据图，不是原图尺寸；
- sobel_binary.png：复刻中值+Sobel的二值结果；
- candidate_overlay.png：RGB565量化后的原图与候选框；
- result.json：所有区域、拒绝原因、框与标注匹配；
- 总summary.json：配置/源文件hash、按split/scene统计TP/FP/FN、precision/recall。

默认IoU≥0.5，用一对一最大匹配避免一个框重复算多个TP。无预测/无真值导致分母为零时输出null，不伪装100%。未标注样本不进入准确率。

标注ROI中的Y/Cb/Cr分位数包含框内背景，仅用于观察，不能直接当作新的肤色阈值。当前实际RTL仍按扫描顺序保留前8个合格区域，软件参考也如此，没有偷偷加入第二阶段排序。
