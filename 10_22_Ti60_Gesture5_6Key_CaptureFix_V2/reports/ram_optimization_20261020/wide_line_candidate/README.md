# 宽行缓存额外压缩候选

本目录完全隔离于活动源；生成和验证时没有修改 `src/vision/line_buffer_3x3.v`。

候选 `line_buffer_3x3.v` 保留 DWIDTH 1/2 的原打包路径，仅在可获益几何采用宽字打包：3～10 位且 WIDTH≤512，或6～10位且1024<WIDTH≤1536。其他尺寸保持原分离路径，避免3～5位1280列增加RAM，或640列增加无收益的选择逻辑。1280 像素拆为 512+512+256，读 bank 选择寄存与 RAM 同步读同拍。非法 x 地址与原实现保持未知值读语义，写地址仍由原有效范围保护。

## 2026-10-20 实测

使用同一 Ti60F225 C4、Efinity 2025.1.110.5.9 和主工程综合参数；微型顶层将全部窗口、坐标、有效信号输出，避免存储被裁剪。

| WIDTH1280 / DWIDTH8 | 当前 | 候选 | 变化 |
|---|---:|---:|---:|
| RAM10 | 4 | 3 | -1 |
| LUT4 | 80 | 115 | +35 |
| FF | 140 | 142 | +2 |
| ADD | 23 | 23 | 0 |
| DSP | 0 | 0 | 0 |

这是独立综合测量，最终工程资源和时序需以整机重新布局布线为准。微型综合快照保留了初版宽缓存条件；后续仅收紧尺寸适用条件，上表1280列8位路径完全一致。最终候选收紧条件后重跑了全部18组等价。

XSim 2018.3 逐周期全部输出比较 **PASS**：18 组配置、90,000 时钟；含原 9 组回归，新增 DWIDTH3/4/5/9/10、8位裁剪坐标、319列尾 bank，以及 1280/319 列非法读取。覆盖稀疏 DE、两次异步中途复位、逐帧清零及有效窗口计数保护。

证据：`current/outflow/wide_line.map.out`、`candidate/outflow/wide_line.map.out`、`equivalence.log`、`comparison.json`、`input_hashes.json`。

## 复现

在本目录执行 `./test_candidate.ps1` 和 `./map_candidate.ps1`。`test_candidate.ps1 -CandidateFile <绝对路径>` 可直接验证采用后的生产源，仍对照本目录固定的当前快照。当前电脑旧 XSim 的 MinGW DLL 在沙箱内重定位失败；使用进程级非沙箱执行可通过，无须修改安装或系统环境。脚本仅写入本目录。

候选与当前快照均已保存。`prepare_candidate.py` 为首次生成脚本，采用后无需重新运行它；复现测试直接使用现有候选和快照文件。
