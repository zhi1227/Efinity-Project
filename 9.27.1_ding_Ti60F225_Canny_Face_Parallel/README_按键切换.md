小核心板上的 **K1** 每按下并松开一次，模式加一。默认模式 3。
循环：3 → 4 → 5 → 6 → 7 → 0 → 1 → 2 → 3。
按下和松开均需稳定约 20 ms；长按只切换一次。
下载时若一直按住 K1，不切换，先松开再按。模式在显示帧边界生效。

| 模式 | 显示 |
|---|---|
| 0 | 原始彩色画面 |
| 1 | 黑底白色 Canny 边缘 |
| 2 | 彩色图叠加边缘及候选框 |
| 3 | 默认：黑底白色 Canny 边缘及红色候选框 |
| 4 | 候选区域中的 Canny 边缘突出显示 |
| 5 | 左半灰度、右半二值 Sobel，中央青线 |
| 6 | 原始肤色掩膜：白色为符合肤色阈值的像素 |
| 7 | 多数滤波和腐蚀后的肤色掩膜 |

从默认画面按两次到 5，三次到 6，四次到 7。若串口切过模式，从当前模式继续加一。
UART 115200 8N1 的 0–7、m、+、-、r 仍然有效；r 恢复模式 3 和阈值 40/80。
同一时钟遇到 UART 模式命令和按键事件时，UART 模式命令优先；调阈值命令不丢按键事件。
