# Ti60F225 Project1：M7 肤色与三类手势修复

工程入口 `Ti60_Demo.xml`，Ti60F225/C4、OV5640、1280×720 HDMI。原工程与学长参考工程保留。修改前源码、测试、工具和位流位于 `rollback/before_m7_fix_*`；旧 bit SHA256：`F96CF58E747D8E4B737DBC1EC1D4AD911F160E15B138183C72BE529B48CC55E8`。

## 操作

- 下载后默认 M3 SOBEL，边缘阈值100。K1短按下一模式、长按约0.8秒上一模式，M0～M7循环。
- K2在M0～M6调边缘阈值，短按+5、长按−5，范围0～255；在M7调肤色R−G下限，初值10、范围0～85、步进5，上限固定90。
- 两套参数独立保存，在下一帧生效。`RG:10`表示`10<R−G<90`，下限越高条件越严格。
- 消抖20ms，长按一次只触发一次，松开不追加短按。
- K1=N2/CSI，K2=M2/CSO。**K3/RESET=J5/CRESET_N是硬件复位，不能切换模式。** SRAM下载掉电失效，硬复位可能载入Flash中的旧程序。

| 模式 | 内容 |
|---|---|
| M0 | 原始彩色图像 |
| M1 | 灰度 |
| M2 | 3×3中值 |
| M3 | Sobel黑底白边 |
| M4 | Prewitt黑底白边 |
| M5 | Sobel后腐蚀 |
| M6 | 腐蚀后膨胀 |
| M7 | 肤色白色掩膜、最大有效目标红框、A/F/R及手势 |

## M7处理与统计

肤色借鉴学长 `易灵思传统算法/Ti60F225_SC1336_HDMI_Display/src/new/face_reader_720p.v` 的实际RTL条件`10<R−G<90`。补充R>B和亮度32～240，亮度系数77/150/29。保留OV5640现有自动白平衡，没有复制SC1336的红蓝增益。

处理链为：RGB→肤色二值化→半径3圆盘低通（29点中至少15点）→3×3腐蚀→3×3膨胀→八连通域。M7不再提取Sobel稀疏边缘，手掌内部保留为白色。窗口边界填黑，完整输出1280×720，各分支、坐标和同步一起延迟。

连通域使用游程、上一行表和父标签合并。选择实际前景像素最多的有效域，同面积优先靠上、再靠左。宽高至少40，面积2500～460800，填充率至少150‰，触及5像素处理边界的目标无效。容量为1024标签、64候选和1024条待处理游程；容量超限或帧间计算未完成时整帧无效，显示OVF。未移植参考工程的人脸过滤及断桥规则。

- A：选中连通域的真实肤色像素数。
- F：`floor(1000*A/(W*H))`，千分填充率，范围0～1000。旧的外接框/极值更新次数已停用。
- R：`floor(1000*H/W)`，千分高宽比；W、H均包含框的两端像素。
- 红框与A/F/R来自同一个最近完成帧，一起更新；无有效目标时一并清零。进入M7或调整参数后，先丢弃过渡帧，再统计完整帧。

## 三类规则与实测

以下为**待现场校准的初始区间**，不代表已验证的真人准确率：

| 标签 | 姿势 | F | R |
|---|---|---|---|
| PALM | 全掌 | 250～600 | 650～1500 |
| FIST | 拳头 | 700～1000 | 650～1500 |
| FINGER | 一指 | 250～750 | 1600～3500 |
| NONE | 无目标或区间外 | — | — |

连续三帧同类才显示标签，无效或未知目标立即清除标签。分类区间和目标有效参数位于`src/project1/ep1_components.v`，肤色保护参数位于`src/project1/ep1_skin.v`。K2不改变分类区间。

先在M0核对颜色，再在M7核对手是否形成完整白色区域。固定摄像头、均匀光照，单手和简单背景，掌心朝镜头、指尖向上，尽量减少前臂入镜。颜色接近肤色的背景仍可能被分割出来，应先验收掩膜再校准分类。

每类记录不少于30帧A/F/R到`reports/FIELD_CALIBRATION.csv`，据样本范围校准并保留独立验证样本。每类重复展示10次，每次保持2秒，观察最后1秒；空场景持续10秒应为NONE，移走手后两帧内清零。区间重叠或分类失败必须记录未通过，不能以红框出现代替识别成功。状态见`reports/BOARD_ACCEPTANCE.md`。

## 复现

在工程目录执行：

```powershell
python -B tools/reference.py
python -B tools/reference_m7.py
./tools/test_rtl.ps1
./tools/build_ti60.ps1
./tools/program_sram.ps1
python -B tools/record_delivery.py
```

本机Vivado xsim执行离线仿真，Efinity2025.1完成编译。下载脚本验证位流哈希、扫描Ti60 `0x10660A79`，然后以6MHz JTAG配置SRAM，不写Flash。正常构建无需运行初始迁移脚本`tools/prepare_project.py`。

报告、日志和哈希位于`reports/`。HUD预览是RTL仿真渲染，不是板卡照片；Python只生成离线参考，FPGA上不运行Python，也未增加串口通信。
