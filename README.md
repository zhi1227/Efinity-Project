# Efinity FPGA 图像处理工程

最后更新：**2026-09-22（北京时间，UTC+8）**

本仓库用于整理易灵思 Ti60F225 开发板的学习例程和实时图像处理工程，当前重点是全国大学生嵌入式芯片与系统设计竞赛 2026 易灵思方向的赛题四“基于 FPGA 的实时图像边缘检测系统”。

主要硬件链路为：

~~~text
OV5640 摄像头 → FPGA 图像处理 → DDR3 帧缓存 → HDMI 1280×720
~~~

## 重点工程：9.22.2_ding_Ti60F225_Canny_Face_Parallel

工程说明全文见 [9.22.2_ding_Ti60F225_Canny_Face_Parallel/README_赛题四.md](9.22.2_ding_Ti60F225_Canny_Face_Parallel/README_赛题四.md)，这里给出摘要。

### 并行结构

~~~text
OV5640 DVP → 采集与裁剪 → DDR3 控制器/异步 FIFO → lcd_driver 寄存 RGB 与 DE/HS/VS
                                                      ├─→ 灰度 → 3×3 中值 → Sobel → NMS → 双阈值 → 局部滞后 → 二值边缘
                                                      ├─→ YCbCr 肤色 → 多数滤波 → 腐蚀 → 8×8 网格 → 八连通 BFS → 人脸框
                                                      └─→ RGB565/控制/坐标 RAM 延迟补偿
                                                      → 五模式融合 → HDMI TMDS
~~~

两条分支采样同一 DDR 显示像素流，Canny 不给肤色分支喂数据，人脸检测也不阻塞边缘输出。核心计算全部在 FPGA RTL 内完成，Python 仅用于工程审计与测试资料整理，未参与板上算法。

### 算法要点

- RGB565 高位复制扩展为 RGB888；灰度为 `(77R+150G+29B)>>8` 的移位加法，无除法器。
- 3×3 中值比较网络去椒盐噪声，按最初需求替代高斯，属于 Canny 变体。
- 3×3 Sobel 取 `|Gx|+|Gy|`，保留 12bit；梯度方向分 0/45/90/135 度，边界用幅值 2:1 近似。
- NMS 沿方向比较两邻居（`center>n1 && center>=n2`），固定打破平局，避免阶跃双像素边缘。
- 双阈值默认低 40 / 高 80；滞后为**单次局部 8 邻域连接**，不是递归追踪，不能声称与完整离线 Canny 严格等价。
- 人脸分支：YCbCr 整数变换（Y=40..235、Cb=77..127、Cr=133..173）→ 3×3 五票多数滤波 → 3×3 腐蚀 → 8×8 占据网格（≥24 为前景，160×90 双缓冲）→ 八邻域 BFS → 最多 8 个候选框 → 宽高与填充率过滤。
- 准确名称是“基于肤色分割、形态学处理和连通域分析的人脸候选区域检测”，不是神经网络或身份识别。

### 显示模式与在线参数

原 peri.xml 未启用板载按键端口，为保留既有引脚配置，本版通过已约束的 UART RX 调参；**“板载按键＋消抖”高阶项尚未完成**。UART 配置为 115200、8 数据位、无校验、1 停止位：

| 字符 | 功能 |
| --- | --- |
| `0` | 原始彩色 |
| `1` | 纯黑底白色二值 Canny，不画框 |
| `2` | 彩色原图＋绿色普通边缘＋框内黄色边缘＋红框 |
| `3` | **默认：黑底白色边缘＋红框** |
| `4` | 黑底，框内黄色边缘，框外暗灰边缘，红框 |
| `m` | 在 0..4 循环 |
| `+` / `-` | 低阈值 ±8，高阈值 ±16 |
| `r` | 恢复模式 3、阈值 40/80 |

阈值在输入帧边界生效，模式在显示帧边界生效。现有 UART IO 约束为 **1.8V**，外接时请使用开发板原配接口或匹配电平，不要按 3.3V 裸 IO 推断。

### 延迟与帧发布

Canny 分支为 4 行＋18 拍，融合前彩色/控制/坐标打包进同一 RAM 延迟；融合输出再寄存 1 拍，共 **4 行＋19 拍 = 6619 拍**，按保留的 74.4MHz 约 88.97μs（不含摄像头与 DDR 帧缓存延迟）。肤色形态学分支为 2 行＋2 列，共 **3309 拍**。

人脸框不是当前像素的即时结果：第 N 帧网格在完整捕获后由后台 BFS 计算，仅在下一个显示 VS 上升沿发布，因此正常显示使用 **N−2 帧**的已完成结果，框不会在帧内改变。默认最坏全前景 720p 实测 BFS 为 443411 个时钟（约 5.96ms），720p 每帧有 1237500 时钟的后台预算；超时则锁存 LED[4] 报警并丢弃该次网格，不影响 HDMI。

### 上板验收与已知限制

JTAG 枚举到 1 个 Ti60，ID `0x10660A79`，下载退出码 0；最终默认模式 3 已由用户确认“已是黑底白边，红框正常”。记录见 `reports/board_acceptance.md`。

必须准确说明的差异：

1. 官方 Canny 高阶项写的是高斯滤波，本版按初始许可选择中值变体，滞后为局部一次连接。
2. 官方要求板载按键/拨码调阈值，本版只有已约束 UART，该硬件交互高阶项未完成。
3. 官方基础显示描述为灰度/边缘分屏或画中画，本版提供全屏切换与彩色像素叠加，未实现严格分屏/画中画布局。
4. 人脸候选是并行肤色网格八连通，不是官方示例的“从边缘中识别圆/矩形”，属扩展性质。
5. 存在两帧框延迟、8px 框量化、无帧间平滑；局部弱边链可能断裂；中值可能删除很窄线条。
6. 没有录制演示视频，未用外部设备量化帧率与长时间丢帧率。

## 赛题四进度汇总

已实现：

- OV5640 摄像头采集与 1280×720 HDMI 稳定显示；
- 移位加法加权灰度、3×3 中值滤波；
- 3×3 Sobel 的 Gx、Gy 与 `|Gx|+|Gy|`，两行 Line Buffer；
- NMS、双阈值二值化、局部滞后连接、去孤立点；
- DDR3 帧缓存与逐像素流水；
- 灰度/边缘、彩色叠加、黑底白边等多种显示模式；
- UART 在线调整阈值与模式（9.22.2）。

正式提交赛题四前仍需优先补齐：

- 板载按键/拨码实时增减阈值（含消抖），以覆盖官方硬件交互高阶项；
- 严格的灰度/边缘分屏或画中画布局；
- 演示视频、摄像头实际帧率与长时间丢帧率测试说明；
- 可选：把中值切换为高斯，形成标准 Canny 对比模式。

Canny 属于赛题四的高阶挑战，不替代基础要求。推荐先完善稳定的 Sobel 赛题版本，再以 9.22.2 的并行工程作为进阶演示。

## 打开与编译

工程主要使用 Efinity 2025.1。进入具体项目目录后打开 **Ti60_Demo.xml**，或在 PowerShell 中运行：

~~~powershell
& 'C:\Efinity\2025.1\bin\efx_run.bat' Ti60_Demo --prj -f compile
~~~

9.22.2 工程也可直接使用官方脚本（CLI 已实测可运行，不必先开 GUI）：

~~~powershell
& 'C:\Efinity\2025.1\bin\python3.bat' 'C:\Efinity\2025.1\scripts\efx_run.py' Ti60_Demo.xml --flow compile
~~~

临时 JTAG 下载：

~~~powershell
& 'C:\Efinity\2025.1\bin\efx_run.bat' Ti60_Demo --prj -f program --pgm_opts mode=jtag
~~~

JTAG 下载写入易失 SRAM，断电后需要重新下载。写入 SPI Flash 前应确认工程、目标器件和启动模式。
