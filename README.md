# Efinity FPGA 学习与图像处理工程

最后更新：**2026-09-21 00:12（北京时间，UTC+8）**

本仓库用于整理易灵思 Ti60F225 开发板的学习例程和图像处理项目，包括 LED、摄像头采集、HDMI 显示、Sobel 边缘检测及人脸候选区域检测相关工程。

## 当前重点项目

- `FPGA_Sobel/`：原始 GitHub Sobel 参考工程，面向 Altera 平台，不能直接下载到 Ti60F225。
- `Ti60F225_GitHub_FPGA_Sobel_Port/`：适配 Ti60F225 的 Sobel 移植版，使用 OV5640、DDR3 和 HDMI，输出 1280×720 图像。
- 核心板 **K1** 用于切换黑白边缘和赛博风格彩色边缘；默认黑白模式，短按一次切换一次。
- 详细操作见 [Sobel 移植版说明](Ti60F225_GitHub_FPGA_Sobel_Port/README.md)，在 Efinity 2025.1 中打开该目录下的 `Ti60_Demo.xml`。
