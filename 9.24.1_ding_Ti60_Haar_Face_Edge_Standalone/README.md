# Ti60 独立 Haar 人脸框与框内边缘工程

2026-09-24 新建。上一版已由用户确认绿色框明显稳定、离开后会消失，但首次检出常超过 3 秒且近距离容易漏检。本次增加补扫位置、均值缩图、提前发布和大脸尺度，并加速积分图读取；七项回归和完整构建均已通过，已通过 JTAG 下载，现场照片已确认人脸框和框内白色边缘，首次出框速度与更近距离效果仍待确认。详见 reports/board_feedback.md。

## 功能

OV5640 → 原 DDR 视频底座 → 720p HDMI；后台采集一幅 160×90 稳定灰度快照，经完整 25 级、2913 弱分类器 Haar 级联扫描，在人脸矩形内显示 Sobel 白色边缘。没有使用肤色阈值作为人脸判据。

Haar 检测使用新写的单路 Verilog，模型参数来自 Cornell facedetect-fpga 的 Baseline（commit 515ddd9d5f9ad9636c5bd9c5e080d787741de2ec），保留 `model/LICENSE_Cornell`。eigenpi 用作架构评估参考；本工程不是其整包 VHDL 的原样移植，也不使用 Intel IP 或 Xilinx HLS 生成 IP。保留原板级 Efinix DDR/FIFO 等 IP。

此处“轮廓”是用户确认的“人脸框内真实图像边缘”，会包含眼睛、鼻子、头发等内部边缘，不是纯脸颊/下巴的语义外边界，也不是身份识别。

## 默认画面与试用

默认模式 1：彩色原图 + 绿色人脸框 + 框内白色 Sobel 边缘。

先在均匀光照下正对摄像头，保持双眼、鼻子和嘴完整在画面内。当前覆盖十三个离散检测尺度：192、216、240、264、288、336、384、432、480、528、576、624、672 像素的正方形窗口；小于最小窗口的脸、侧脸、遮挡、脸部被画面裁切、强逆光及尺度间隙仍可能漏检。不要将仿真通过当作实景准确率证明。

板端串口若已连接，可用 115200、8N1 发送单个 ASCII 字符（无需回车）：

| 字符 | 显示/操作 |
|---|---|
| 0 | 原始彩色画面 |
| 1 | 默认：彩色 + 绿色框 + 框内白边 |
| 2 | 灰度 + 绿色框 + 框内白边 |
| 3 | 黑底 + 红框 + 仅框内白边 |
| 4 | 全画面 Sobel，排查边缘链路 |
| m | 循环显示模式 |
| + / - | Sobel 阈值每次 ±16，帧边界生效 |
| r | 恢复模式 1 与 Sobel 阈值 80 |

串口改的是边缘阈值，不是 Haar 分类阈值。UART TX 当前保持高，无运行数据回传。LED[4] 是候选簇或保留跟踪槽容量超出 8 个、或跟踪输入溢出的锁存标志；不是检测忙或 FPS 指示。没有新增物理按键/引脚复用。

## 实际结构与预算

- 视频端从灰度输入形成一组 3×3 窗口，Sobel L1 = |Gx|+|Gy|。
- 预融合延迟 `H_TOTAL+1+4=1655` 拍，融合另寄存一拍。完整 RGB/DE/HS/VS 同步延迟，窗口无效边界填零。
- 每 8×8 灰度像素求平均并四舍五入为 8 bit，160×90 灰度帧在 Haar 计算期间不再写入。缩图只增加一行 160×14 bit 部分和缓存，降低单点抽样的混叠。忙时跳过显示帧，不阻塞 HDMI。
- 同一快照按十三个尺度复用同一块积分图 RAM，尺寸为 ceil(1280/stride) × ceil(720/stride)，stride 为 8、9、10、11、12、14、16、18、20、22、24、26、28。窗口步长仍为 2，相邻四轮依次覆盖起点偏移 (0,0)、(1,0)、(0,1)、(1,1)，避免一直遗漏相同位置。
- 积分图四角地址连续发出，利用同步 RAM 两拍读取延迟，原来每个矩形 12 拍的四角读取改为 6 拍；同一模型的全部分类条件保持不变。
- 积分图按 18 bit、平方积分图按 26 bit 模加存储。对最大 24×24 矩形，像素和≤146880、平方和≤37454400，因此矩形差分可恢复精确值；方差与平方根运算使用更宽位宽，避免沿用上游 32-bit 溢出风险。
- 模型阶段阈值沿用 Cornell 的 0.4 倍策略，用整数 `ceil(2*t/5)` 等价实现。
- 相交候选按中心落入已有框的规则合并，最多 8 个；这是简单去重，不是置信度 NMS。随后对相邻检测结果做一对一最近中心关联，每次坐标按新旧各 1/2 平滑；没有身份识别或运动预测。
- 每次发现新的、已通过全部 25 级的候选簇即申请发布，无需等十三尺度全部结束。跟踪端按就绪握手接收，在显示帧边界发布。每个框独立计时，允许 36 个显示帧未再次检出（约 60 Hz 时为 0.6 秒），超时自动清框，即使检测核心停止输出也会清除。空检测不立即清框。消失时间从上次结果发布计算，还需考虑快照采集与检测延迟。
- 保持期间 R00、B1 可以同时出现：当前扫描没有检出，但显示端在短暂保留最近有效框；这不算新的成功检测。框内边缘仍来自当前实时画面。
- `frame_id` 是所截取的显示扫描帧序号，不是摄像头独立源帧 ID。相机帧率和显示刷新率不同仍可能重复采样相机帧。

## 本次验证证据

1. `sim/tb_haar.log`：普通真实测试图、由该图构造的大脸样本、均匀空场景各覆盖四种扫描相位，共 12 轮；全部候选坐标和尺寸与独立 C++ 整数参考逐一吻合。大脸样本包含超过 384 像素的有效候选；四轮空场景均为 0。
2. 同一普通测试图的相位 0 完整扫描从上一版 6,678,150 拍降为 4,806,015 拍，按 74.399 MHz 为 89.76 → 64.60 ms，减少约 28%。首次候选为 450,731 拍，即约 6.06 ms。这是样本计算耗时，不是所有真人都能在该时限内检出的承诺。
3. `sim/tb_haar_video.log`：完整两帧 720p，共 1,843,200 有效像素，控制/RGB 延迟与 Sobel 坐标通过。
4. `sim/tb_haar_integration.log`：720p RGB565 量化路径、完整缩图快照、补扫相位轮转、提前发布、帧内框稳定及后续空场景清框。首次候选到显示约 8.71 ms，并早于整轮完成；默认 36 帧保持由独立跟踪测试覆盖。
5. `sim/tb_haar_tracker.log`：默认保持、坐标平滑、独立消失、检测停止后过期、容量限制、过期重获及过期竞态通过。
6. `sim/tb_gray_thumbnail.log`：8×8 精确平均、间断有效信号、全白最大值和跨帧重新累加通过。`sim/tb_haar_selftest.log`：启动自检预期 11 个原始候选、测试框不进入实景，以及自动切换摄像头通过。
7. `sim/tb_haar_near.log`：完整 720p 输入的大脸样本经过 RGB565、均值缩图与 Haar 后，显示框宽度超过旧版 384 像素上限；后续空场景清框和采集边界检查通过。
8. `reports/build.log` 与 `outflow/Ti60_Demo.timing.rpt`：综合、接口、布局布线及位流生成通过，13 个 setup 与 13 个 hold 时钟关系全部为正。
9. JTAG 下载结果以 `reports/jtag_program.log` 和 `reports/board_feedback.md` 中对应位流哈希为准。

默认接口底座的未使用 DSI/LCD 等端口告警仍存在。新增 RAM 截断为受范围约束地址及模运算；ROM 初始化已进入综合网表。DSP `CE permanently disabled` 对应坐标映射乘法器，其 A_REG_USE_CE=0，启用寄存器不使用该 CE；并非运算被停止。没有使用放宽时序约束的办法消除违例。

现场 HDMI 正常、自检通过及无遮挡正脸出现绿色框已由用户确认；上一稳定性修订已由用户确认框明显稳定且离开后会消失；本次框内白色边缘已由现场照片确认；首次响应、更近距离效果以及长时间稳定性仍待现场反馈。JTAG 完成只证明下载，不代表实景检测质量已验收。

## 文件与复现
