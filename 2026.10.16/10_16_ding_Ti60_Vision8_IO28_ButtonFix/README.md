# Vision8 IO28 按键修复版（2026-10-16）

本工程是独立副本，修正 IO28 外接机械按钮的有效电平和长按临界释放处理。用户确认该按钮松开约3.3 V、按下约0 V；本版按**低有效**识别。原先高有效解释会把松开当作按住，启动时的“先释放才能武装”保护因而无法正常完成。另修正长按到达2秒边界时释放可能同时产生长、短按事件的问题。

本次交付修改后的完整摄像头／DDR／八模式工程源码及仿真结果。**按用户要求已停止bit流编译，没有交付新bit/hex。** 后续由用户打开 [Ti60_Demo.xml](Ti60_Demo.xml) 自行完整编译，生成 `outflow/Ti60_Demo.bit/.hex`。接线、SRAM测试和验收表见 [IO28按键修复与接线验收_20261016.md](IO28按键修复与接线验收_20261016.md)。**本次未执行JTAG下载、Flash写入或实物按键验收。**

IO28固定为 **P4.33 / User_3V3_IO28 / FPGA C1**。正式接法只使用“信号与按下接地”两线：确认常开触点后，OUT接P4.33，按下与OUT导通的一端接P4.30 GND，原接3.3 V的第三根线拆除并绝缘。三脚位置必须通过断电通断测试确认，不能按VCC/GND字样猜触点关系。IO35/P4.40保持原有高有效阈值页功能；本工程没有把PiP迁移到IO35。

摄像头保持上一版V3 B设置：`RGB_BALANCE_ENABLE=0`、`RGB_BALANCE_PROFILE_ENABLE=0`、`LENC_ENABLE=0`，即空间RGB调色旁路、OV5640镜头补偿关闭。摄像头初始化、数据链路、DDR、图像算法、LVDS和电子纸源码沿用；色圈问题仍须实物对照确认。历史摄像头A/B试验见 [摄像头官方对照与上板验收_V3.md](摄像头官方对照与上板验收_V3.md)，该文档中的旧bit和旧报告不代表本次按键修复构建。

## 八模式的用途

IO28 短按按下表顺序循环，屏幕编号为 1～8；源码内部编号为 0～7。

| 屏幕模式 | 用处与主要操作 |
| --- | --- |
| 1 原图 | 查看摄像头彩色视频；IO29 短按冻结/恢复。当前空间RGB调色旁路，可在此模式观察白色、灰色和肤色。 |
| 2 Canny 黑白边缘 | 查看 Canny 边缘；IO28 长按开关右上角彩色画中画；通过 IO35 进入阈值页。 |
| 3 彩色红边 | 在彩色视频上显示 Sobel 红色边缘；支持彩色画中画。 |
| 4 赛博边缘 | 显示 Sobel 赛博风格边缘；支持彩色画中画。 |
| 5 彩边对照 | 同屏左侧彩色视频、右侧 Canny 边缘；用于观察同一画面的原图与提边效果。 |
| 6 手势识别 | 先录入张掌、点赞、单手比心，再进行三类识别；张掌往返摆动触发招手反馈。 |
| 7 人脸候选数量 | 显示满足当前肤色、轮廓、尺寸条件的候选数；有效空画面为0、超量为8+、无有效结果为--。这是候选检测，不是身份识别或累计进出人数。 |
| 8 四帧对比 | K2 选择原图/Canny/红边/赛博算法，IO29 短按依次保存到四格，长按清空；第5次覆盖第1格。 |

四帧按处理结果降采样为 640×360 RGB565，记录算法、Canny 阈值及源帧编号；忙时忽略新抓拍和算法切换。已提交图片在模式切换后保留，存放于 DDR，断电或重新配置后丢失。画中画为 320×180 彩色摄像头图像。切换模式会请求恢复实时画面。

电子纸仍由 RISC-V 在启动后显示原静态人物图片、全刷一次后休眠；不随手势或模式换图。当前没有接入旋转编码器或外接图片 Flash 换图功能。

第一轮菜单预览：[八模式主菜单](reference/previous_ui_preview/menu_0.png)、[独立阈值页](reference/previous_ui_preview/menu_12.png)。图片来自第一轮HDL输出RGB流的仿真渲染，17帧已检查布局，**不是实物屏幕截图**。

## 五键接线与完整操作

| 按键 / 顶层端口 | 扩展口物理脚 | FPGA 球位 / GPIO | 空闲→按下 |
| --- | --- | --- | --- |
| IO28 / `io28_button_i` | P4 / DC3-40 第33脚 | C1 / GPIOL_N_16 | **高→低，本次修正** |
| IO29 / `io29_button_i` | P4 / DC3-40 第34脚 | D1 / GPIOL_P_16 | 高→低 |
| IO35 / `io35_button_i` | P4 / DC3-40 第40脚 | B9 / GPIOT_P_11 | 低→高 |
| 板载 K1 / `key_mode_n` | 板载按钮，无需外接P4 | N2 / GPIOL_P_02 | 高→低 |
| 板载 K2 / `key_freeze_n` | 板载按钮，无需外接P4 | M2 / GPIOL_N_02 | 高→低 |

FPGA侧为 **1.8 V LVCMOS 输入**；IO28保留 `pull_option=none`。P4的User_3V3信号经底板TXS0108E电平转换，默认连接器侧为3.3 V。TXS0108E自带上拉，IO28松开时由其保持高电平，按下由干接点拉到GND。不要将FPGA输入改成3.3 V或输出，也不要盲加下拉。IO35仍需明确的空闲低、按下高电平，不能把本次IO28的两线接地法直接套到IO35。

全部按钮双级同步、约20 ms双边消抖。短按在松开时执行；IO28稳定按下满2秒时识别一次长按，继续按住不重复，松开不再补短按。上电或复位时已按住的按钮须先稳定松开再重新按下。按住按钮跨页面或模式时取消旧上下文动作；IO28只在模式2、3、4且未打开阈值设置页时由长按切换PiP。

| 操作 | 普通模式页面 | 模式6 手势 | 模式8 四帧 | IO35 阈值设置页 |
| --- | --- | --- | --- | --- |
| IO28 短按 | 下一模式 | 下一模式，退出未完成录入 | 下一模式 | 关闭设置并切到下一模式 |
| IO28 长按 | 仅模式2～4开关画中画；其余无动作 | 无动作 | 无动作 | 无动作 |
| IO35 短按 | 打开阈值页 | 打开阈值页 | 打开阈值页 | 返回进入前的算法模式 |
| IO35 长按 | 无动作 | 无动作 | 无动作 | 无动作 |
| IO29 短按 | 冻结/恢复 | 仅非录入期间冻结/恢复 | 保存一帧；忙时忽略 | 减少所选阈值 |
| IO29 长按 | 无动作 | 无动作 | 清空四格 | 冻结/恢复 |
| K1 短按 | 无动作 | 确认当前录入步骤 | 无动作 | LOW→HIGH→LINK |
| K1 长按 | 无动作 | 进入/重新录入，并恢复实时画面 | 无动作 | 步长1→4→8 |
| K2 短按 | 无动作 | 无动作 | 原图→Canny→红边→赛博；忙时忽略 | 增加所选阈值 |
| K2 长按 | 无动作 | 无动作 | 无动作 | 无动作 |

表中“普通模式”指模式1～5、7。打开/关闭阈值页保持原 HDMI 算法、冻结状态及已调阈值；要观察边缘变化，先选模式2再打开阈值页。Canny 默认 LOW=40/HIGH=80，限制 `1 ≤ LOW < HIGH ≤ 2040`；LINK 同增同减、保持间距，到边界停止。参数在帧边界生效。此页只调整 Canny，不调整 Sobel 或 RGB。

## 手势录入与使用

1. IO28 短按切到**模式6**，确认摄像头画面实时变化；长按板载 K1 约2秒进入录入。
2. 张开手掌，掌心完全盖住粉色小框（32×32采样，中心约560,360）。手和指尖放入大 ROI `(40,40)～(1000,680)`，只允许手腕从底部伸出。
3. K1 短按确认，按倒计时保持稳定约2秒；随后依次录入拇指向上的点赞、单手拇指/食指交叉比心，每步均由 K1 短按确认。点赞与比心保持轮廓明显不同，查看右侧黑白轮廓预览。
4. 完成后，张掌先等“手掌已确认”提示，再左右摆动并回摆；静止张掌、轻抖和单向移动不会触发招手。点赞、比心保持录入时的方向并停稳片刻。
5. 肤色失败、轮廓不稳或手型太相似时，按屏幕提示调整位置/照明后重试；K1 长按从张掌重新录入。录入中切换模式会取消未完成流程。

样本只在运行状态中保存：切换模式、冻结/恢复保留已录入样本；上电、复位或重新下载后重新录入。固定RGB参数改变后也应重新录入肤色与手势。此实现依赖个人轮廓模板和肤色条件，复杂背景、遮挡或姿态变化仍会影响效果。
